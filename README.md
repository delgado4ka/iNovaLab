# iNovaLab

Single-page informational website for iNovaLab.

**Stack:** [Astro](https://astro.build) (static output) · React (interactive islands only) · TypeScript · Tailwind CSS v4 · [shadcn/ui](https://ui.shadcn.com)

## Getting started

Requires Node.js 22+.

```bash
npm install
npm run dev       # http://localhost:4321
```

| Command           | What it does                              |
| ----------------- | ----------------------------------------- |
| `npm run dev`     | Dev server with hot reload                |
| `npm run check`   | Type-check `.astro` and `.ts/.tsx` files  |
| `npm run build`   | Build static site into `dist/`            |
| `npm run preview` | Serve the built `dist/` locally           |

## Project structure

```
src/
├─ data/                  # ALL editable content (text, contacts, lists). Edit here.
├─ assets/images/         # Images (optimized by Astro at build time)
├─ components/
│  ├─ ui/                 # shadcn components (generated by the CLI)
│  ├─ sections/           # Page sections (.astro): Hero, About, Contacts, ...
│  └─ interactive/        # React components that need JS in the browser
├─ layouts/BaseLayout.astro  # <html>, <head>, SEO meta
├─ pages/index.astro      # The page: composes sections in order
├─ lib/utils.ts           # cn() class helper
└─ styles/global.css      # Tailwind + theme colors / fonts
```

## Editing content

Change text in `src/data/*.ts`. Each file is typed, so `npm run check` catches missing or misspelled fields.

## Adding shadcn components

```bash
npx shadcn@latest add accordion
```

Components land in `src/components/ui/`. They render as static HTML when used in `.astro` files. If a component needs to be interactive in the browser (accordion, dialog, carousel...), wrap it in a React component in `components/interactive/` and use it with a client directive, e.g. `<Faq client:visible />`.
